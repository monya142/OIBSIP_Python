# Python Voice Assistant.
This project is created for the OASIS INFOBYTE Python Internship.
## Features
- Responds to "Hello"
- Tells current time
- Tells today's date
- Searches Google using voice commands
- ## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- datetime
- webbrowser
# to Run
1. Install required libraries
2. Run `voice_assistant.py`
3. Speak commands through microphone
